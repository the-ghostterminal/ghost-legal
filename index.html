Ghost Terminal Publisher

A private, single-operator publishing tool. It takes short educational videos that the channel owner has already produced and uploads them to that same owner's YouTube channel through the YouTube Data API.

What it does

  • Uploads video files from the operator's own machine to the operator's own YouTube channel.
  • Sets the title, description, tags and category on those uploads.
  • Uploads a custom thumbnail for those videos.
  • Reads back the channel's own video list and per-video statistics (views, likes, comments) so the operator can see what performed.

Who can use it

One person: the owner of the YouTube channel The_GhostTerminal. There is no sign-up, no user accounts and no public interface. The tool runs locally on the operator's computer, and the only Google account it can ever reach is the one the operator explicitly authorizes through Google's own OAuth consent screen.

What it does not do

  • It does not access any other channel's private data.
  • It does not upload, comment, message or interact on anyone else's behalf.
  • It does not read viewers' personal information, watch history or emails.
  • It does not collect analytics beyond the aggregate counts YouTube returns for the operator's own videos.
  • It has no advertising, no tracking pixels and no third-party analytics.

How it connects to Google

Authorization uses Google OAuth 2.0 with the following scopes: youtube.upload, youtube.readonly and youtube.force-ssl. The resulting token is stored only on the operator's machine and can be revoked at any time from the Google Account permissions page. Details are in the Privacy Policy.

Compliance

This application uses YouTube API Services. By using it, the operator is bound by the YouTube API Services Terms of Service and the Google Privacy Policy. See also our Terms of Service.
