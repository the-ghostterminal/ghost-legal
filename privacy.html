Privacy Policy

Effective 12 November 2026 · applies to Ghost Terminal Publisher

Ghost Terminal Publisher is a private tool used by one person to publish videos to that person's own YouTube channel. It is not a service offered to the public, it has no end users other than its operator, and it does not sell, rent or share data.

1. Who is responsible

The operator of the YouTube channel The_GhostTerminal, reachable at 46752934+the-ghostterminal@users.noreply.github.com.

2. What Google user data is accessed

Only after the operator grants consent through Google's OAuth screen, and only for the operator's own Google account:

ScopeDataPurpose
youtube.upload Permission to upload video files and set thumbnails on the operator's channel Publishing the operator's own videos
youtube.readonly Channel identity, the channel's own video list, and per-video public counts (views, likes, comments) Confirming an upload succeeded and reporting performance
youtube.force-ssl Permission to update metadata (title, description, tags, visibility) on the operator's own videos Correcting or completing a published video's details

No other Google user data is requested. The tool never requests access to Gmail, Drive, Contacts, Calendar, watch history or any other Google service.

3. How the data is used

Google user data is used for exactly one purpose: publishing and managing the operator's own videos on the operator's own channel, and reading the resulting public statistics back. It is never used for advertising, profiling, resale, model training or any secondary purpose.

4. How the data is stored

  • The OAuth client credentials and refresh token are stored in a single file on the operator's computer, readable only by the operator's operating system account (file mode 0600).
  • No Google user data is sent to any server operated by this project. There is no backend, no database and no cloud storage.
  • Video files are read from local disk and streamed directly to YouTube. They are not copied anywhere else.
  • API responses (video titles and aggregate counts) are shown to the operator in a terminal and may be written to local logs on the same machine.

5. Sharing and disclosure

Google user data is not shared, sold, transferred or disclosed to any third party, except as required by law. The only destination for the data is Google's own YouTube Data API.

6. Retention and deletion

  • Local tokens are kept until the operator deletes them (yt-auth --revoke removes the file).
  • Authorization can be revoked at any time at myaccount.google.com/permissions; revocation stops all further API access immediately.
  • Local logs can be deleted by the operator at any time; they contain no third-party personal data.
  • Deleting a token file does not delete anything on YouTube. Videos and their metadata are removed through YouTube Studio, by the channel owner.

7. Google API Services User Data Policy — Limited Use

Ghost Terminal Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Data is used only to provide the single publishing feature described above.
  • Data is not transferred to third parties except as necessary to provide that feature, to comply with applicable law, or as part of a merger or acquisition with prior notice.
  • Data is not used for serving advertisements, including personalised or retargeted advertising.
  • Data is not used to determine creditworthiness or for lending purposes.
  • Humans do not read the data, except where the operator is the human reading their own data, or where required for security, legal compliance or with explicit consent.

8. Security

Credentials live in a permission-restricted local file, all API traffic uses HTTPS, and the tool requests the narrowest scopes that can do the job. No credential is ever transmitted to a third party. Access tokens are held in memory or a short-lived local cache and expire within an hour.

9. Children

The tool is not directed to children and has no users other than its adult operator. It collects no data from any third party, including children.

10. Changes to this policy

If this policy changes, the revised version is published on this page with a new effective date.

11. Contact

Questions or deletion requests: 46752934+the-ghostterminal@users.noreply.github.com
